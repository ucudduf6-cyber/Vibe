# Worker PWA

Разместите ВСЮ папку на HTTPS-хостинге (например GitHub Pages), сохранив структуру файлов. На iPhone откройте сайт в Safari → Поделиться → На экран «Домой». Иконка, короткое имя и автономное окно задаются manifest.json и iOS meta-тегами.

Темы: настройки профиля → цветовая схема, светлая/тёмная. Сохраняются в localStorage. Язык сохраняется как русский; переводов интерфейса на другие языки нет. Звук по источникам — локальные настройки; при подключении сервера их следует учитывать при формировании push.

Service Worker обеспечивает кэширование и обработчик входящих push, но **сам по себе не отправляет push**. Для уведомлений при закрытом приложении необходимы сервер с Web Push/VAPID, хранение подписок и вызов pushManager.subscribe() с публичным VAPID-ключом, а также отправка подписки на сервер. iOS поддерживает web push для установленных на экран «Домой» PWA на совместимых версиях iOS. Разрешение запрашивается только после нажатия пользователя. Если уведомления запрещены в системе, включать их нужно в настройках устройства.

Сайт по-прежнему локальный прототип: нет сервера пользователей, настоящих диалогов или удалённой доставки. Не используйте для конфиденциальной информации.
