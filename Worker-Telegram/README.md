# Worker Messenger — Telegram-inspired prototype

Загрузите **содержимое** этой папки (index.html, manifest.json, sw.js, assets/) в корень репозитория GitHub Pages. Путь сайта: https://USERNAME.github.io/REPOSITORY/.

Реализовано: адаптивный интерфейс мессенджера, локальные диалоги, группы и каналы, поиск, отправка текста и небольших файлов, настройки профиля, 6 тем с тёмным режимом, локальные истории, настройки звука, PWA.

ВАЖНО: это frontend-прототип, а не Telegram и не его полноценная копия. Сообщения, истории и файлы хранятся только в localStorage данного браузера. Нет аккаунтов, настоящих пользователей, доставки сообщений, звонков, синхронизации, серверной модерации, шифрования end-to-end и push-доставки. Для этого требуется backend, база данных, авторизация, WebSocket, объектное хранилище и сервер Web Push. Не используйте прототип для приватной переписки.
