# Vibe — социальная сеть (мобильный прототип)

## Как запустить с телефона через GitHub
1. Создай новый репозиторий на GitHub.
2. Загрузи `index.html` из этого архива в корень репозитория (Add file → Upload files).
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/ (root)`, нажми Save.
5. После публикации открой адрес вида `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Что уже работает в прототипе
- адаптивный красивый интерфейс для телефона и компьютера;
- лента, демонстрационные карточки постов, лайки и выбор реакции;
- создание текстовых публикаций и загрузка небольших фото/видео;
- профиль, истории, личные каналы (максимум 5);
- переключение между лентой, сообщениями, каналами и профилем;
- сохранение данных в localStorage этого браузера.

## Важно
Это frontend-прототип, а не полноценная многопользовательская соцсеть: публикации и загруженные файлы хранятся только в браузере на этом устройстве. Другие пользователи не увидят их, а реальные аккаунты, синхронные личные сообщения, серверное хранение медиа, подписки и настоящие истории на 24 часа потребуют backend и базу данных. Не загружай сюда личные или чувствительные данные. Фото/видео для локального демо ограничены 1,8 МБ.
