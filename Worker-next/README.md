# Worker — локальный прототип

Новая версия: W в шапке, создание через «+», реакции на сообщения, аватары групп и каналов, описания, отдельные фоны чатов, черно-белая тема, локальные переключатели блокировки и приватности.

**Важно:** регистрация/вход, поиск пользователей на разных устройствах, реальная блокировка и полноценная админ-панель требуют сервера, авторизации, базы данных и проверки прав на сервере. Не выдавайте локальные переключатели за серверную защиту. Администраторам нельзя предоставлять скрытый доступ к приватным личным перепискам: для поддержки используйте обращения пользователей и явное согласие.

Разместите содержимое этой папки в корне GitHub Pages.
