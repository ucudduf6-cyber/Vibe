Worker — обновлённая локальная демоверсия.

В настройках: скрытие и восстановление папок «Личные», «Группы», «Каналы» (папка «Все» обязательна), 17 цветовых тем включая монохромную, фото профиля с круглым предпросмотром, инструкция установки на iPhone и Android. В настройках каждого чата доступны отдельные фото и цвета фона.

Загружайте СОДЕРЖИМОЕ папки в корень GitHub Pages, а не папку целиком. Для реальной переписки нужен backend.
